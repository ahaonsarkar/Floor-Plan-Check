# 2D Floor Planning Evaluation System - Project Context

## Project Overview

This is an **Automated 2D Floor Planning Evaluation System** that processes architectural floor plan images to automatically detect and extract key structural elements: **rooms, walls, doors, and windows**. The system consists of a Python backend for computer vision processing and a React frontend for visualization and interaction.

## Purpose & Goals

The system aims to:
1. **Automate floor plan analysis** - Convert raw floor plan images into structured, machine-readable data
2. **Enable architectural evaluation** - Provide quantitative data about room layouts, wall structures, and openings
3. **Support design workflows** - Give architects/designers a tool to quickly digitize and analyze 2D floor plans
4. **Serve as a foundation** - Build a platform for further analysis (space utilization, circulation paths, code compliance, etc.)

## Backend Components (Python + OpenCV)

### 1. Wall Detection (`Backend/processing/wall_detection.py`)
- **Class**: `WallDetector`
- **Purpose**: Identifies wall segments from preprocessed binary images
- **Algorithm**:
  - Binarizes grayscale image using configurable threshold (default: 128)
  - Extracts external contours using `cv2.findContours`
  - Filters by minimum area (100 pixels) to remove noise
- **Output**: List of wall segments with:
  - Unique ID
  - Full contour coordinates
  - Bounding box (x, y, width, height)
  - Area in pixels

### 2. Room Detection (`Backend/room_detector.py`)
- **Main Function**: `detect_rooms(binary_image, ...)`
- **Purpose**: Identifies enclosed spaces (rooms) from binary floor plan
- **Pipeline**:
  1. **Contour Extraction** - Finds external contours (`cv2.RETR_EXTERNAL`)
  2. **Filtering** - Removes contours by:
     - Minimum area (default: 150 px²)
     - Perimeter-to-√area ratio (default: 0.3) - rejects elongated noise
  3. **Polygon Approximation** - Douglas-Peucker algorithm (`cv2.approxPolyDP`) with configurable epsilon (default: 0.01)
  4. **Labeling** - Assigns sequential labels (`room_1`, `room_2`, ...)
- **Parameters**:
  - `min_area`: Minimum room size
  - `min_perimeter_ratio`: Shape regularity filter
  - `epsilon_factor`: Polygon simplification level
- **Output**: Dictionary mapping room labels to coordinate polygons
- **Utilities**: `rooms_to_json()`, `save_rooms_to_file()`

### 3. Door & Window Detection (`Backend/door_window_detector.py`)
- **Main Function**: `detect_openings(binary_wall_image, ...)`
- **Purpose**: Identifies and classifies wall openings as doors or windows
- **Algorithm**:
  1. **Inversion** - Inverts binary image so gaps become white shapes
  2. **Gap Contour Extraction** - Finds external contours in inverted image
  3. **Filtering** - By area (default: 50 px²) and perimeter ratio (default: 0.2)
  4. **Classification Heuristics**:
     - **Door**: Height ≥ 120px AND width/height ≤ 0.6 (vertical/tall)
     - **Window**: Area ≤ 2% of image area AND aspect ratio 0.5-2.0 (square-like)
     - **Other**: Falls through (ignored)
- **Parameters**:
  - `min_gap_area`, `min_gap_perimeter_ratio`: Noise filtering
  - `door_min_height`, `door_max_aspect`: Door criteria
  - `window_max_area_ratio`: Window size threshold
- **Output**: `{"doors": [[x,y],...], "windows": [[x,y],...]}`
- **Utilities**: `openings_to_json()`, `save_openings_to_file()`

## Key Design Decisions

1. **Modular Pipeline** - Each detection (walls, rooms, doors/windows) is independent, allowing:
   - Parallel development
   - Independent parameter tuning
   - Selective execution

2. **Binary Image Assumption** - All detectors expect preprocessed binary images, separating:
   - Preprocessing (thresholding, noise removal, line thinning) from
   - Semantic detection (what is a room vs wall vs opening)

3. **Heuristic Classification** - Door/window classification uses geometric rules rather than ML:
   - Transparent, tunable parameters
   - No training data required
   - Fast inference

4. **JSON as Interchange Format** - Language-agnostic, human-readable, easy to debug

5. **CLI Entry Points** - Each detector can run standalone for testing:
   ```bash
   python room_detector.py <binary_image_path>
   python door_window_detector.py <binary_image_path>
   ```

## Usage Example

```python
# Full pipeline
from Backend.processing.wall_detection import WallDetector
from Backend.room_detector import detect_rooms, save_rooms_to_file
from Backend.door_window_detector import detect_openings, save_openings_to_file
import cv2

# 1. Load and preprocess (needs implementation)
image = cv2.imread("floorplan.png", cv2.IMREAD_GRAYSCALE)
# binary_image = preprocess_image(image)  # threshold, denoise, skeletonize

# 2. Detect walls
wall_detector = WallDetector(threshold=128)
walls = wall_detector.detect(binary_image)

# 3. Detect rooms
rooms = detect_rooms(binary_image, min_area=200, min_perimeter_ratio=0.25)
save_rooms_to_file(rooms, "rooms.json")

# 4. Detect doors/windows
openings = detect_openings(binary_image, min_gap_area=80, door_min_height=150)
save_openings_to_file(openings, "openings.json")
```
